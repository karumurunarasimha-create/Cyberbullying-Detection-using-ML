# Cyberbullying Detection Using Machine Learning

## Project Overview

Cyberbullying Detection Using Machine Learning is an academic project focused on identifying potentially harmful or abusive content on social media platforms using machine learning techniques.

The project includes datasets related to Twitter hate speech and Wikipedia attacks, along with trained model files and a web-based application interface.

## Project Objectives

- Identify potentially harmful content in social media text.
- Apply machine learning to text classification.
- Support the analysis of cyberbullying-related content.
- Present prediction results through a web interface.
